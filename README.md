# SVG CLI：分步协作学习版

这是一个独立的新仓库，用于重新开展真实的、适中粒度的 AI 辅助编程过程。
旧工程是参考版本；本仓库不会把旧工程的完成记录当作用户参与的学习过程。

## 当前增量

第一轮目标：`init → create rect → tree → move → tree`。
此初始提交只有工程配置与设计草案，功能尚待实现。
后续按讨论进度增加其他图形、容器、撤销重做与 SVG 读写。

## 环境

Node.js 18.17 或更新版本，npm。安装开发依赖：`npm ci`。

架构与真实过程记录见 [doc/README.md](doc/README.md)。
